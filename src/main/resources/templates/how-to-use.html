How to Use — Timetable Generator

A quick guide to get from empty setup to a generated timetable.

Setup Steps (do once per semester)

1

Add Department

Go to Departments → fill name (e.g., Information Technology), code (e.g., IT), and HOD. Click Create Department.

2

Add Divisions (Classes)

Go to Divisions → add each class: SE-IT (Sem 4, 4 batches, prefix S), TE-IT (Sem 6, prefix T), BE-IT (Sem 8, prefix B). Also set Lab Time Preference per division.

3

Add Classrooms & Labs

Go to Classrooms → add all lecture rooms (Type: Classroom) and lab rooms (Type: Lab). The generator assigns rooms automatically based on type.

4

Configure Time Slots

Go to Time Slots → add slots for the day: 09:00–10:00, 10:00–11:00, then add 11:00–11:15 as a Break, then 11:15–12:15, 12:15–13:15, add 13:15–14:00 as Break (Lunch), then afternoon slots. Also tick working days (Mon–Fri).

5

Add Subjects

Go to Subjects → for each subject set: Name, Code, Department, Semester, Type (Theory/Lab/Audit), Lecture hours/week, Practical hours/week, Practical slot duration (usually 2 for 2-hour labs).

6

Add Faculty & Assign Subjects

Go to Add Faculty → create each teacher's login. In Subjects Handled field, enter a comma-separated list of subject names they teach (used by the generator to assign faculty to slots).
Then go to Assign Subjects to set primary faculty per subject.

7

Generate Timetable

Go to Generate Timetable → click Generate. The system places all subjects, labs (with batch rotation), and audits automatically. Check the placement count — ideally 100%.

8

View & Export

View the result on Weekly Grid or Table View. Use Export PDF to download the master timetable. Add any fixed slots (INTERNSHIP, AUDIT COURSE etc.) via Special Slots before exporting.

Important Notes

  • Generating again clears the old timetable — do this only when needed.
  • Faculty are matched by Subjects Handled — keep those up to date.
  • For lab subjects with different teachers per batch, make sure each teacher has the lab name in their Subjects Handled.
  • Break/Lunch slots marked in Time Slots are never scheduled.
  • The generator respects faculty conflicts — no teacher is double-booked in the same time slot.
