3

Lab Time Preference — what it means

This controls which 2-hour window the generator prefers for lab rotation:

MORNING → Window A (09:00–11:00) · BE-IT MIDDAY → Window B (11:15–13:15) · TE-IT AFTERNOON → Window C (14:00–16:00) · SE-IT

Set this correctly. Wrong Lab Time Preference causes window conflicts between divisions — the most common reason for large numbers of failed sessions.

Subject type guide

  • Theory — whole-class 1-hr lecture. Set only lecture hours.
  • Lab — batch rotation, 2-hr window. Set practical hours + duration.
  • Audit — fixed whole-class session (e.g., Audit Course). Pin via Special Slots.
  • Special — no-faculty sessions: Library, Internship, VL, T&P.

Same subject has theory AND lab? Create two entries: one for theory (e.g., MIL — 1 lecture hr) and one for lab (e.g., MILL — 2 practical hrs). The generator handles them independently.

Subjects Handled — most important field

The generator uses this to know which faculty can be assigned to which session. Key rules:

  • Values must exactly match the Subject Name (case-sensitive).
  • Separate multiple subjects with a comma: Computer Graphics, Computer Graphics Lab
  • No leading or trailing spaces around subject names — CG Lab ≠ CG Lab
  • For labs where batches are split (e.g., SSK takes S1/S2, ARD takes S3/S4), both faculty list the lab — the per-batch split is done in Step 7.

How to assign

  • Select the Subject from the dropdown.
  • For each batch row, select the assigned faculty.
  • Click Save Assignment.
  • Repeat for every split-faculty lab subject.

These assignments are the primary input for faculty conflict detection. If two batches share the same faculty for the same lab, the generator must spread them across different days — incorrect assignments are the #1 cause of failed lab sessions.

8 Generate Timetable

One click runs the full algorithm — understand the output to verify everything placed correctly

1

Go to /auto-generate → click Generate

The algorithm runs in 2–5 seconds. A successful run shows:

✓ Placed 200 of 200 requested sessions
✓ Generation complete — no warnings

If some sessions couldn't be placed:

⚠ Placed 197 of 200 requested sessions
⚠ Could not place Social Computing [BE-IT] (lecture 2/3)
⚠ Could not place Social Computing [BE-IT] (lecture 3/3)
2

Understanding warnings

WarningRoot causeFix
Could not place [subject] (lecture N/X)No free slot — faculty conflict or room conflictCheck faculty load; add more lecture rooms
Lab rotation slot N/N could not be placedAll day-window combinations occupied or conflictReview batch-faculty assignments in Step 7
Could not place practical blockAll windows on all days occupiedPin session via Special Slots (Step 8)
3

What the generator guarantees

  • No faculty double-booked — same teacher never in two slots simultaneously.
  • No room double-booked — same room never has two sessions at the same time.
  • Break and lunch slots are never used.
  • Lab sessions always use a full 2-hour window (A, B, or C) — never 1 hour.
  • Theory slots use only lecture rooms; labs use only lab rooms.
  • No subject appears twice on the same day unless unavoidable.

Regenerating clears the entire timetable and rebuilds from scratch. Always export before regenerating to avoid losing manual edits.

10 View & Export

Three views to inspect the timetable — export to XLSX (multi-sheet) or PDF

1

View Timetable — searchable table

Filterable list of all placed sessions. Each row shows day, slot, subject, faculty, room, and batch. Use the Edit button on any row to fix individual entries without regenerating.

2

Weekly Grid — classic day × time view

Rows = days, columns = time slots. Lab rotation cells show all 4 batches per slot: S1→CGL(PGK), S2→DBMSL(RAN) ...

Use the Add Entry button on this page to manually add a single slot. The form provides dropdowns for Class (SE(IT)/TE(IT)/BE(IT)), Batch (S1–S4/T1–T4/B1–B4), Time Slot, Subject, Faculty, and Room — no free-text typing needed.

3

Export XLSX — multi-sheet workbook

Click Export XLSX on the View Timetable page. Downloads a single Excel file containing:

SheetContent
SE_IT, TE_IT, BE_ITClass timetable — full week grid with lab rotations, batch legend, class teacher, signatures
MASTERAll 3 divisions stacked on one sheet for a combined overview
Fac_PGK, Fac_ANK …Individual faculty timetable — one sheet per teacher showing their own slots across all classes
Room_305, NL, WET …Room occupancy — one sheet per room showing which session/batch occupies each slot

Each sheet includes the institution header (logo, record number, revision, DoI) and a signature footer (TT Coordinator, HOD, Principal) from Institution Settings.

4

Export PDF — print-ready via XLSX conversion

Click Export PDF on the View Timetable page. The server generates the XLSX and converts it to PDF using LibreOffice in headless mode. Download and print directly — A4 landscape, fitted to page.

PDF conversion requires LibreOffice installed on the server. If the PDF download fails or shows an error, verify LibreOffice is installed: libreoffice --version

11 Troubleshooting & Checklist

Common problems, fixes, and a pre-generation checklist

!

Sessions placed < requested

  • Faculty overload — a teacher is assigned too many hours. Check Subjects Handled list and redistribute labs.
  • Room shortage — 3 divisions competing for 2 Classroom-type rooms. Add a 3rd Classroom-type room.
  • Wrong Lab Time Preference — two divisions use the same window. Verify Step 2 preferences (AFTERNOON / MIDDAY / MORNING).
!

Wrong faculty in lab rotation cell

Go to Assign Subjects → find the lab → verify each batch's faculty. Update and regenerate.

!

Subject appears twice on the same day

The generator always tries to spread subjects across different days. A same-day repeat means no other day had a free slot. Options: reduce total hours, add a lecture room, or reduce another subject's hours.

!

XLSX type shows as "Lecture" in Classrooms list

Old data may have been saved as "Lecture" type before the standardisation. The app auto-migrates these to "Classroom" on each restart. If you see "—" instead of a type badge in the Classrooms list, go to Classrooms, edit the room, and re-save it as Classroom.

!

Recycle Bin

Deleted subjects, faculty, or rooms go to /recycle-bin. Restore any item deleted by mistake. Items in the Recycle Bin are invisible to the generator.

 Pre-generation checklist — verify all items before clicking Generate

  • Department created with correct name and code
  • All 3 divisions added with correct Batch Prefix, Total Students, Roll Number Start, Class Teacher, and Lab Time Preference
  • Classroom-type rooms (305, 306) and Lab-type rooms (IT-203 to IT-206) added
  • All 9 time slots added — Short Break (slot 3) and Lunch (slot 6) ticked as Break
  • All subjects added with correct type, lecture hours, and practical hours
  • All faculty added with exact Subject Names in Subjects Handled
  • Batch→faculty assignments set for all split-faculty lab subjects
  • Special slots pinned: VL (Fri 16:00), INTP (Mon+Thu 14:00), Audit, Seminar, T&P
  • Institution Settings updated: Academic Year, Semester, W.E.F. date, DoI, logos uploaded
